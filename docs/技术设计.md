## 2. Provider 层设计（可配置生图 API）

### 2.1 统一接口

```ts
// src/main/providers/types.ts
export type Capability = 'txt2img' | 'img2img' | 'inpaint' | 'controlnet' | 'upscale'

export interface ProviderConfig {
  id: string
  type: 'sd-webui' | 'comfyui' | 'openai-compat' | 'custom-http'
  name: string
  enabled: boolean
  baseUrl: string
  apiKeyRef?: string          // 指向 safeStorage 加密后的密文 key，不存明文
  options: Record<string, unknown>  // 各类型专属参数
  createdAt: number
  updatedAt: number
}

export interface GenerateRequest {
  prompt: string
  negativePrompt?: string
  width: number
  height: number
  seed: number | 'random'
  steps?: number
  cfgScale?: number
  sampler?: string
  initImage?: string          // base64/路径，img2img 用
  denoise?: number            // img2img 强度
  controlnet?: {
    module: 'openpose' | 'depth' | 'canny' | 'lineart'
    image: string
    weight: number
  }
  count?: number
}

export interface GenerateResult {
  images: Array<{ path: string; seed: number; width: number; height: number }>
  meta: {
    providerId: string
    model?: string
    sampler?: string
    durationMs: number
    raw?: unknown             // 原始响应，便于排错
  }
}

export interface ImageProvider {
  readonly config: ProviderConfig
  readonly capabilities: Capability[]
  testConnection(): Promise<{ ok: boolean; message: string; models?: string[] }>
  generate(req: GenerateRequest, onProgress?: (p: number) => void): Promise<GenerateResult>
}
```

**设计要点**

- UI 按 `capabilities` 动态启用/禁用「动画帧（需 img2img + controlnet）」「局部重绘」等功能，并给出降级说明
- 所有 Provider 返回统一 `GenerateResult`，管线不感知后端差异
- 原始响应保留在 `meta.raw`，便于用户排错

### 2.2 各 Provider 实现要点

| 类型 | 连接 | 关键接口 | 说明 |
|---|---|---|---|
| **SD WebUI** | 默认 `http://127.0.0.1:7860` | `GET /sdapi/v1/sd-models`、`/options`；`POST /sdapi/v1/txt2img`、`/sdapi/v1/img2img` | ControlNet 通过 `alwayson_scripts.ControlNet` 传参；启动需 `--api`（跨域加 `--cors-allow-origins=*`） |
| **ComfyUI** | 默认 `http://127.0.0.1:8188` | `POST /prompt`、`GET /history/{id}`、`GET /view` | 每种任务内置一个工作流 JSON 模板，用占位符注入参数；`/ws` 订阅进度 |
| **OpenAI 兼容** | 用户填 baseUrl | `POST /v1/images/generations`（可选 `/edits`） | 支持各类中转；不保证 img2img，能力按实测声明 |
| **自定义 HTTP** | 用户填 URL | 任意 | Body 模板 + 图片提取 JSONPath + 轮询配置，覆盖自建服务 |
| ~~Stability 官方~~ | — | `POST /v2beta/stable-image/generate/*` | V2 计划，当前未实现 |

### 2.3 配置页交互（Providers.vue）

1. 列表：服务卡片（名称、类型、状态灯、当前模型、设为默认、测试连接、编辑、删除）
2. 新增向导：选类型 → 填地址/密钥 → 测试 → 拉取模型列表 → 保存
3. 状态提示：连接失败给出针对性建议（端口未开 / 缺 `--api` / 密钥无效 / 模型未加载）
4. 密钥：仅写入 `safeStorage`，界面上只显示掩码；导出配置时剔除密钥

## 3. 生成管线

### 3.1 精灵动画帧（核心链路）

```
① 动作定义      { name:'walk', frames:8, fps:12, loop:true, canvas:128x128, pivot:'bottom-center' }
② 母版生成      单帧全身参考图（风格锚点 + seed 固定）
③ 姿态骨架序列  按动作程序化生成 OpenPose 骨架（正向运动学，见 image/pose.ts）
④ 逐帧生成      img2img(母版, denoise 0.38~0.62) + controlnet(openpose, weight 0.85)
⑤ 去底裁切      alpha 阈值分割 → 去孤立噪点 → bbox 裁剪
⑥ 对齐          脚底基线对齐 + 水平中心轴对齐 + 统一画布居中
⑦ 校验          bbox 宽高偏差 >15% 或中心位移 >10% → 标红待重生成
⑧ 排布          横向/网格图集 + 生成 SpriteFrames
```

**一致性策略分级（按 Provider 能力自动选择）**

| 级别 | 条件 | 手段 | 预期质量 |
|---|---|---|---|
| A | 本地 SD + ControlNet | 母版 img2img + OpenPose 骨架 + 固定 seed | 最佳，帧间姿态稳定 |
| B | 支持 img2img 无 ControlNet | 母版 img2img + 高 denoise 变化 + 严格裁切对齐 | 可用，幅度大的动作易崩 |
| C | 仅 txt2img | 固定 seed + 固定提示词模板 + 后期对齐 | 仅适合幅度小的待机动作 |

> UI 必须在生成前提示当前 Provider 所属级别，避免用户对结果预期错误。

**自动对齐算法（image/align.ts）**

1. 扫描 alpha 通道得到主体 bbox
2. 取 bbox 底部 10% 区域的最宽水平线段 → 估计脚底基线
3. 按配置的 canvas 尺寸与 pivot 重排：`dx = canvasW/2 - bboxCenterX`，`dy = canvasH - baselineOffset - bboxBottom`
4. 输出统一尺寸画布，保证直接切帧不错位

### 3.2 静态资源 / 瓦片

- **图标**：批量并发生成（默认并发 2），统一后处理为 256×256 居中方形，输出 PNG
- **九宫格**：生成整图后按配置的边距切片，输出 `9-slice.png` + 边距元数据
- **瓦片**：生成后做四边镜像混合，计算四边像素差值生成无缝度评分（<阈值视为合格），输出可平铺瓦片

## 4. Godot 导出

### 4.1 输出格式

```gdscript
# idle.tres（Godot 4.x）
[gd_resource type="SpriteFrames" format=3]

[ext_resource type="Texture2D" path="res://assets/generated/hero/idle.png" id="1_atlas"]

[sub_resource type="AtlasTexture" id="AtlasTexture_f0"]
atlas = ExtResource("1_atlas")
region = Rect2(0, 0, 128, 128)

[sub_resource type="AtlasTexture" id="AtlasTexture_f1"]
atlas = ExtResource("1_atlas")
region = Rect2(128, 0, 128, 128)

[resource]
animations = [{
"frames": [{"duration": 1.0, "texture": SubResource("AtlasTexture_f0")},
{"duration": 1.0, "texture": SubResource("AtlasTexture_f1")}],
"loop": true,
"name": &"idle",
"speed": 12.0
}]
```

### 4.2 导出策略

- 每个动作独立 png + tres，避免单文件过大导致编辑器卡顿
- 路径默认 `res://assets/generated/<name>/`，可配置根目录
- 不生成 `.import` 文件，交由 Godot 首次导入时创建（避免版本差异导致的损坏）
- 同时输出 `meta.json`：动作参数、Provider、模型、seed、风格包版本，便于复现
- 提供「纯 PNG 导出」模式，供非 Godot 引擎使用

## 5. 数据模型

### 5.1 当前实现（v0.1，JSON 存储）

MVP 阶段未引入 SQLite，改用 `userData/data/store.json` 单文件存储，避免原生模块在 Electron 下的 ABI 重编译问题。

```jsonc
{
  "version": 1,
  "providers": [
    {
      "id": "uuid",
      "type": "sd-webui",
      "name": "本地 SD",
      "enabled": true,
      "baseUrl": "http://127.0.0.1:7860",
      "model": "v1-5-pruned-emaonly.safetensors",
      "options": { "controlnetModel": "control_v11p_sd15_openpose", "sampler": "DPM++ 2M Karras" },
      "apiKeyCipher": "base64(safeStorage 加密)",   // 密钥仅密文落盘
      "createdAt": 0,
      "updatedAt": 0
    }
  ]
}
```

写入采用「临时文件 + rename」，避免中断导致配置损坏；默认服务在内存中维护，后续可持久化。
替换为 SQLite 时保持 `providerStore` 的接口不变即可。

### 5.2 规划中的 SQLite 结构（V2）

素材与任务历史量大后再迁移，表结构如下：

```sql
-- 项目
CREATE TABLE project (
  id TEXT PRIMARY KEY, name TEXT NOT NULL, root_path TEXT,
  created_at INTEGER, updated_at INTEGER
);

-- 生图服务配置（密钥单独加密存储）
CREATE TABLE provider (
  id TEXT PRIMARY KEY, project_id TEXT, type TEXT NOT NULL, name TEXT NOT NULL,
  base_url TEXT, options_json TEXT, enabled INTEGER DEFAULT 1,
  is_default INTEGER DEFAULT 0, created_at INTEGER, updated_at INTEGER
);

-- 风格包
CREATE TABLE style_pack (
  id TEXT PRIMARY KEY, project_id TEXT, name TEXT,
  prompt_template TEXT, negative_prompt TEXT, seed INTEGER,
  ref_image_path TEXT, controlnet_json TEXT, created_at INTEGER
);

-- 素材（单帧或整图）
CREATE TABLE asset (
  id TEXT PRIMARY KEY, project_id TEXT, style_pack_id TEXT,
  kind TEXT,              -- sprite_frame | icon | tile | ui9
  action TEXT, frame_index INTEGER,
  file_path TEXT NOT NULL, width INTEGER, height INTEGER,
  provider_id TEXT, seed INTEGER, params_json TEXT,
  status TEXT,            -- ok | needs_review | failed
  created_at INTEGER
);

-- 任务
CREATE TABLE job (
  id TEXT PRIMARY KEY, project_id TEXT, type TEXT,
  payload_json TEXT, status TEXT, progress REAL,
  error TEXT, created_at INTEGER, finished_at INTEGER
);
```

## 6. IPC 接口（preload 暴露）

```ts
window.api = {
  providers: {
    list(): Promise<ProviderConfig[]>
    upsert(cfg: ProviderConfig): Promise<ProviderConfig>
    remove(id: string): Promise<void>
    test(id: string): Promise<{ ok: boolean; message: string; models?: string[] }>
    setDefault(id: string): Promise<void>
    models(id: string): Promise<string[]>
  },
  generate: {
    sprite(payload: SpriteJobPayload): Promise<{ jobId: string }>
    icons(payload: IconJobPayload): Promise<{ jobId: string }>
    cancel(jobId: string): Promise<void>
    onProgress(cb: (e: { jobId: string; stage: string; progress: number }) => void): () => void
  },
  export: {
    godot(payload: { assetIds: string[]; rootDir: string }): Promise<{ files: string[] }>
    png(payload: { assetIds: string[]; dir: string }): Promise<{ files: string[] }>
  },
  project: { open(): Promise<Project | null>; create(name: string): Promise<Project> }
}
```

**安全约束**：`contextIsolation: true`、`nodeIntegration: false`、仅白名单通道可调用、外部 URL 一律经主进程发起。

## 7. 开发顺序（M1 拆解）

1. Electron + Vue + TS 骨架，双向 IPC 打通，窗口安全配置
2. Provider 接口 + 注册表 + **SD WebUI** 适配器（本地优先，动画帧依赖）
3. 配置页最小版：新增 / 测试 / 设默认（先不做自定义 HTTP）
4. 单帧生成 → 去底 → 存库 → 预览，形成最小闭环
5. **ComfyUI** 适配器 + 工作流模板机制
6. OpenAI 兼容 / 自定义 HTTP 适配器
7. 验证：用 walk 8 帧小样跑通级别 A 链路，评估一致性是否达标 → 决定 M3 是否启用备选方案
